# Muhammad Mohsin | Portfolio

My personal portfolio site. I'm a student in Karachi, Pakistan who finds real problems around me and builds tools to fix them.

**Live site:** https://theaibot2011.github.io/mohsin-portfolio/

## About

I'm preparing for my O Levels and spend my free time building websites, tools, and games, and editing videos. I direct AI tools like Claude Code, ChatGPT, and Lovable, test everything, fix the bugs, and ship the result. I don't build random stuff. I build things I actually need.

## Featured Projects

### MonitorTest
**Problem:** My monitor got damaged and my relative had to get it fixed. Buying or repairing a screen in a huge market is risky, and it's easy to get ripped off.
**Solution:** A website that tests a display for dead pixels, color problems, and more, so you can check a monitor yourself before paying.
**Built with:** HTML, CSS, JavaScript, Claude Code

### Login Snaps
**Problem:** I keep my laptop out in the open and other people know my PIN, so anyone could use it without me knowing.
**Solution:** A PowerShell automation that takes a webcam photo every time someone logs in to my laptop, so I can see who used it.
**Built with:** PowerShell, Windows automation
*A personal security project that runs on my own laptop.*

### Graphite (Scientific Calculator)
**Problem:** I was learning logarithms for math contests and couldn't find a scientific calculator online that worked for me.
**Solution:** I built my own scientific calculator web app for practicing and checking my work.
**Built with:** HTML, CSS, JavaScript, Claude Code

### Imposter
A party game with online multiplayer.
**Built with:** Lovable, Supabase

### Video Editing
Edits from my 30-day DaVinci Resolve challenge.
